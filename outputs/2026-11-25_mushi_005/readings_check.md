# 読みの対照表（字幕の文 → 声に渡した文）

漢字が声の文に残っていたら「漢字あり」。声の文はひらがなとカタカナだけにする。

## usagi
| セリフ | 字幕 | 声に渡した文 | 確認 |
|---|---|---|---|
| intro（0.3秒） | この動物、なーんだ？虫めがねで、のぞいてみてね。 | このどうぶつ、なーんだ？むしめがねで、のぞいてみてね。 | OK |
| tap（11.6秒） | わかったら、画面を2回タップしてね。 | わかったら、がめんを、にかいタップしてね。 | OK |
| ready（23.9秒） | わかったかな？ | わかったかな？ | OK |
| ans（27.1秒） | 正解は、うさぎでした。 | せいかいは、うさぎでした。 | OK |
| comment（30.8秒） | 何秒でわかったか、コメントで教えてくださいね。 | なんびょうでわかったか、コメントで、おしえてくださいね。 | OK |
| cta（35.1秒） | 左下をクリックして、ほかの問題にも挑戦してくださいね。 | ひだりしたをクリックして、ほかのもんだいにも、ちょうせんしてくださいね。 | OK |
