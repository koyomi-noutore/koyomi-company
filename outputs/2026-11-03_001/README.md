## 作り方（再現手順）【事実】
作業ファイルは成果物フォルダの外（作業フォルダ `$W`）に置く。成果物フォルダには途中の画像を残していない。

1. フォント：Zen Maru Gothic Bold（SIL Open Font License 1.1）。npm の `@expo-google-fonts/zen-maru-gothic@0.4.2` に入っている TTF を使った。
   `npm pack @expo-google-fonts/zen-maru-gothic@0.4.2 && tar xzf *.tgz` → `package/700Bold/ZenMaruGothic_700Bold.ttf`
2. 絵（`scripts/ep001_pictures.py`。プロンプトは plan.md 2・3章、範囲は `scripts/ep001_diffs.json`）
   ```
   export KOYOMI_IMAGE_USAGE_LOG=outputs/2026-11-03_001/image_usage.jsonl
   for q in 1 2 3 4 5; do python3 scripts/ep001_pictures.py base $q $W; done   # 第1問は見本のコピー
   for q in 1 2 3 4 5; do python3 scripts/ep001_pictures.py edit $q $W 1; done
   python3 scripts/ep001_pictures.py retry 4 2c $W; python3 scripts/ep001_pictures.py retry 5 2a $W
   for q in 1 2 3 4 5; do python3 scripts/ep001_pictures.py compose $q $W outputs/2026-11-03_001; done
   python3 scripts/ep001_pictures.py answers $W outputs/2026-11-03_001
   ```
   - 作業フォルダに途中の画像があれば、APIは呼ばない。AIの絵は毎回違うので、範囲（ep001_diffs.json）は今回の絵に合わせた値。作り直すときは範囲も決め直す。
   - 第5問の元の絵は1回目（`q5_a_v1.png`）を使った。2回目は使っていない。
   - 「消える」の指示文は make_differences.py の KEEP の考え方、「増える・形／向き」は plan.md 3章の文を使った（`KEEP_ALT`・`KEEP_REMOVE`）。
   - 第4問①：描き直しで、お皿の右下の緑の薬味が消えた。元の絵の薬味を、色と楕円で形どおりに切り抜いて右の絵に重ねた（ep001_diffs.json の `keep_green`、`green_keep_mask()`）。薬味は左右で同じ（中心部の差は最大3）。
   - 第4問②：描き直しで口が右向きになり、左の湯気もなくなった。湯気ごと範囲に入れ（範囲を絵の左端まで広げた）、右の絵は「口が右向き・湯気なし」にそろえた。絵の端に接する範囲は、ぼかしで端が薄くならないよう、マスクを外へ広げて作る。
3. こよみ先生：`NODE_PATH=$(npm root -g) node scripts/render_expressions.js $W/owl 480`
   - 正式な描画元 `assets/character/expressions.html` の6表情をそのまま透明PNGにした。まばたき用に、ふつう・かんがえ中の「目を閉じた版」だけを追加で作った（目の部分を横線にしただけ。色・線は元のまま）。
4. 声：`python3 scripts/ep001_voice.py $W/voice`（VOICEVOX、冥鳴ひまり ノーマル speaker=14、speedScale 0.88）。声に渡す文字は字幕と分けている（`VOICE_TEXT`：「山道」→「やまみち」。かぎかっこは外す。`VOICE_KANA`：u2・u3 はアクセントつきのカナで渡す）。全セリフの読み（カナ）は `$W/voice/voice.json` に残る。
5. 音：`python3 scripts/ep001_audio.py $W/voice $W/mix.wav`（BGM・効果音は numpy で合成）
6. 動画：`python3 scripts/ep001_video.py outputs/2026-11-03_001 $W <フォント.ttf> $W/mix.wav`
   - PILでフレームを描き、4つに分けて並列に libx264 へパイプで渡し、最後につないで音を付ける。
   - 1枚だけ確認するとき：`python3 scripts/ep001_video.py --frame <秒> outputs/2026-11-03_001 $W <フォント.ttf> <出力.png>`

## 画面と音の作り【事実】
- 構成と時刻は plan.md 4章どおり（`scripts/ep001_timeline.py`）。合計615秒。
- 難易度カード：右からスライドして入り（こよみ先生にかからないよう左寄せ）、最後の0.4秒で出題画面へフェード。スッという効果音。
- 残り時間のバー：90秒で減る。残り30秒で黄、10秒で赤。残り10秒から1秒ごとにカウント音。数字も表示。
- こよみ先生：ゆらゆら（±3度、3.2秒周期）と上下の小さな揺れ、4.1秒ごとにまばたき。表情は台本の表情（ふつう→かんがえ中→45秒でウインク→かんがえ中→答えでにっこり。第5問の③はびっくり、エンディングはやったー）。
- 45秒のヒント：違いのある辺りを、答えの赤丸より一回り大きい光の輪で7秒間そっと示す（答えの範囲から計算）。輪は右の絵の中だけに描く。キラキラ音つき。
- 答え合わせ：赤丸（番号つき）を、こよみ先生が言うのに合わせて1つずつ、ポンという音つきで出す。左右の絵の両方に出す。赤丸を全部描いてから最後に番号札を描くので、番号札は赤丸の線に隠れない。
- 字幕：文字の高さ72px（画面の高さの6.7%）、こげ茶の箱に白い文字（箱の不透明度92%）。左右の絵の下の余白に置き、右下のこよみ先生とは重ならない。1行18字・2行まで。
- 声の長さ：どのセリフも台本の枠に収まった。ただし難易度カードの読み上げ（3.2〜3.5秒）は3秒のカードより少し長い。そのため「さあ、どうぞ。」などを出題の頭から0.8秒あとにした。エンディングの1つ目（4.35秒）が4秒の枠を超えたので、2つ目・3つ目を0.5秒ずつ後ろへずらした（20秒には収まる）。
- **うんちく 6:04 の新しいセリフ**：音声は6.88秒（読みを直した後）で、8秒の枠（6:04〜6:12）に収まった。うんちくの時間配分は変えていない。
- BGM：やさしい和音（Cmaj7→Am7→Fmaj7→G、12秒のループ）と木琴ふうの分散和音。話している間は声の約14dB下（声のRMS −19.9dB、BGM −33.8dB）。黙って探す時間はさらに小さい（−30.9dB）。
- 効果音：ポン、チャイム、カウント音、キラキラ、スッ、ファンファーレ。すべて numpy で合成したオリジナルで、外部の音源は使っていない。
