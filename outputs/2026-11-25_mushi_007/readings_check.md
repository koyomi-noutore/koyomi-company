# 読みの対照表（字幕の文 → 声に渡した文）

漢字が声の文に残っていたら「漢字あり」。声の文はひらがなとカタカナだけにする。

## taiyaki
| セリフ | 字幕 | 声に渡した文 | 確認 |

| intro（0.3秒） | この食べ物、なーんだ？虫めがねで、のぞいてみてね。 | このたべもの、なーんだ？むしめがねで、のぞいてみてね。 | OK |
| tap（12.9秒） | わかったら、画面を2回タップしてね。 | わかったら、がめんを、にかいタップしてね。 | OK |
| ready（25.2秒） | わかったかな？ | わかったかな？ | OK |
