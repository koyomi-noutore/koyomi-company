CEO依頼「Geminiで秋の縁側の絵を作り、間違い探し3つとこよみ先生を重ねた見本」の成果物。本番の回ではなく見本。

## 間違い（やさしい→難しい）
大きさは、出題画面に映る物そのものの幅を画面幅で割ったもの（監査の計測）。answers.json の box_screen_width_pct は答えの範囲の幅で、物より少し大きい。

1. やさしい：竹かごがない（画面幅の約6.8%）
2. ふつう：灯籠の前の紅葉の若木がない（約5.0%）
3. むずかしい：猫のしっぽがない（約3.9%）

いずれも「物がなくなる」違いで、色だけの違いではない。

## 作り方（事実）
- 画像モデル：Gemini `gemini-3-pro-image`（2K）。API呼び出しは計6回（元の絵1＋描き直し3＋監査の差し戻しによる描き直し2）。
- 範囲・指示文・難易度は `scripts/make_differences.py` の `DIFFS` で管理する。AIの描き直しから、その範囲（ぼかし付きマスク）だけを元の絵に貼り戻した。範囲の外は元の絵と同一（ぼかしのにじみを除く）。
- ②は絵全体を描き直させる方式（full）。①③は1回目に消し残りが出たため（監査で不合格）、範囲のまわりを4:3で切り出して大きく描き直させる方式（crop）に変えた。
- 再現の手順：`python3 scripts/make_differences.py <元の絵> <出力> <作業>` → `python3 scripts/compose_sample.py <出力> <作業>/diffs.json`。
- 画面の組み立て：`scripts/compose_sample.py`。絵には文字を入れていない（字幕・タイトルは動画側で入れる）。上下の余白はタイトル・字幕用。
