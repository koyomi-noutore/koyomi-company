CEO依頼「Geminiで秋の縁側の絵を作り、間違い探し3つとこよみ先生を重ねた見本」の成果物。本番の回ではなく見本。

## 間違い（やさしい→難しい）
1. やさしい：竹かごがない（画面幅の8.1%）
2. ふつう：灯籠の前の紅葉の若木がない（5.0%）
3. むずかしい：猫のしっぽがない（4.3%）

いずれも「物がなくなる」違いで、色だけの違いではない。

## 作り方（事実）
- 画像モデル：Gemini `gemini-3-pro-image`（16:9、2K）。API呼び出しは計4回（元の絵1＋描き直し3）。
- 描き直しは絵全体に指示を出し、`scripts/make_differences.py` の範囲（ぼかし付きマスク）だけを元の絵に貼り戻した。範囲の外は元の絵と同一（ぼかしのにじみを除く）。
- 画面の組み立て：`scripts/compose_sample.py`。絵には文字を入れていない（字幕・タイトルは動画側で入れる）。上下の余白はタイトル・字幕用。

## 意見・未決
- 3問とも「消える」型なので、本番では「増える・形が変わる」型も混ぜたほうが飽きにくい。
- こよみ先生の表情は「ふつう」のみ実装。残り5種類は未実装。
