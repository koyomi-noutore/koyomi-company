# かくし絵 試作（2026-11-08・事業部長）

concept.md「新ジャンル」のかくし絵（季節の絵に季節の物が5つ隠れている）の試作1問。画像API 3回（バッチ、約30円）。絵は縮小したJPEG。

| 版 | 隠し方の指示 | 結果（意見） |
|---|---|---|
| A 山道 | 物を他の形にとけこませる | 柿（木のこぶ）・きのこ（岩）・栗が、ふつうの色で描かれ、ひと目でわかる。雲のどんぐりだけ「かくし絵」らしい |
| B 庭 | 同上 | おにぎり・かぼちゃ・ふくろうがはっきり見える。とんぼ（板の木目）・魚（波紋）はかくし絵らしい |
| C 山道 | 線だけで、まわりと同じ色で描く | どんぐり（雲）・もみじ（柵の木目）はよい。柿は目立つ。きのこ・栗は見つけにくい。**①〜⑤の番号の文字が描き込まれた**（不可。答えが分かってしまう） |

## わかったこと（事実）
- 画像AIは「まわりと同じ色・線だけで描く」と指示すると、雲・木目・波紋のように模様のある所にはうまく隠せる。
- 物によっては普通の色で描いてしまい、ひと目でわかる（難しさがばらつく）。
- 番号や文字を描き込むことがある。

## 次の試作の案（意見）
1. 隠す場所は「模様のある所」（雲・木目・波紋・岩の模様・葉の重なり）に限る。
2. 1枚で5つを一度に頼まず、元の絵を描いてから、1つずつ（または5つまとめて）描き直しで隠す（間違いさがしと同じ「範囲だけ貼り戻す」方法）。位置と大きさを自分で決められ、答えの位置もコードで管理できる。
3. 隠れ具合は、画面の大きさで「すぐには見えないが、言われたら分かる」を監査の基準にする。
