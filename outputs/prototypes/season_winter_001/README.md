# 季節の見た目 冬の試作（season_winter_001）
素材：第24回（冬の銭湯）を読むだけで使用。本番データは変更なし。コマは第24回の 3秒（オープニング）・第1問の2秒後（ルール重ね）・第1問の途中・答え・エンディング。

## 使い方
- 色と舞う物は `scripts/season_theme.json`（秋・冬・春・夏・winter_A/B/C）。`ep_video.py` が読む。
- 選び方（優先順）：環境変数 `KOYOMI_THEME` ＞ plan.json の `"theme"` ＞ plan.json の `season` の標準（冬＝今の見た目）＞ 秋。
- 例：`KOYOMI_THEME=winter_A python3 scripts/make_episode.py outputs/<回> frame 8`
- CEOが案を決めたら、season_theme.json の `"冬"` をその案の値で差し替える（`season_default` は変更不要）。
- plan.json の文字色が秋の色（例 [180,70,40]）の場合、テーマの色に自動で置き換わる（完全一致のみ）。
- 一覧：compare.jpg（行＝案、列＝画面）。各案のコマは winter_A/ B/ C/ current/（jpg）。A案の約30秒動画：winter_A_30s.mp4（オープニング〜第1問の途中、音声つき）。
