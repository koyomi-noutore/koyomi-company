# かくし絵 試作3（2026-11-19・制作）

CEO決定（2026-11-19）の「試作2のA＝画像AIの描き直し」方式で、秋の絵1枚に5つの物（柿・どんぐり・もみじ・きのこ・栗）を隠した試作1問。アップロードはしない。
プログラムは `scripts/kakushie_ai.py` の1ファイルだけ（共通のプログラムは変えていない。見本の線画は `scripts/kakushie.py` の形を読むだけ）。

## 結果：監査は不合格（差し戻し1回目）。画像APIの上限（5回）を使い切ったので、ここで止めて報告する
- 重大 K-1：5つとも「塗りと陰影のある物の絵」として描かれ、ひと目で全部見つかる。易しすぎて、隠れていない（audit.md）。
- 位置・文字・季節・番号の入り込みは合格。

## 方式
1. **生成（バッチ1回・3枚）**：場所ごとに「どの面の、どの模様で形を作るか」を指定し、「本来の色で塗らない」「番号・文字・印を入れない」「大きさは絵の幅の8〜10%」「端から8%内側」を強く書いた（prompt.txt）。
2. **選ぶ**：3枚とも5つが描かれ、文字も入らなかった。cand_0 だけが5つとも周りの色だった（栗が水の青）。cand_1・cand_2 は栗が普通の茶色（NG）。
3. **なじませる描き直し（バッチ1回・2枚）**：cand_0 を元に「塗りと陰影をやめ、周りの模様を形の中に通す」を2段階で頼んだ（prompt_blend.txt）。どちらも良くならなかった（栗が茶色になり、どんぐりはより本物らしくなった）。採用は cand_0。
4. **答えの位置**：gemini-3.5-flash（文字で答えるモデル）に5つの枠（box_2d）を答えさせた（cand_*_loc.json → answers.json）。答えの丸は5つとも物の上に正しく乗った（監査で確認）。
5. **画面と動画**：出題画面（左に絵、右に名前と形の見本）・答えの画面（番号の丸）・試作動画 30秒（出題20秒＋答えを1つずつ10秒。声なし）。

## 気づき（事実と意見を分ける）
- 【事実】指示文を細かくすると、試作2の弱点のうち「物が描かれない」「番号の文字が入る」は3枚とも出なかった。
- 【事実】「普通の色で目立つ」は3枚中2枚で残った（栗が茶色）。
- 【事実】大きさは指示の8〜10%を守らず、15.8〜27.7%で描かれた。AIは「隠す物」を主役として大きく、立体的に描く。
- 【事実】描き直しで「なじませて」と頼んでも、隠れ方は変わらなかった。AIの自己評価も visibility 4→3〜4 だった。
- 【事実】位置の読み取りは正確で、答えの丸は手で直さずに使えた。この部分はこのまま使える。
- 【意見】今の画像AI（gemini-3-pro-image）は「物を描く」ことは得意だが、「模様で形を作る（二重の絵）」は苦手。指示文の工夫だけで「ひと目で2つ以下しか見つからない」難しさに届けるのは難しいと考える。
- 【意見】選択肢（CEOに判断をお願いしたい）：
  1. このやさしさを「かくし絵・やさしい版」として認める（探し物クイズに近い）。
  2. 生成の回数を増やして選ぶ（例：1問あたり10枚。約100円/問）。うまくいく保証はない。
  3. 生成した絵の上に、プログラムで周りの模様を重ねて物を薄くする（試作2のBと組み合わせる）。
  4. concept.md の方法③（イリュージョン生成、Replicate・月2,000円）に戻る。
- 軽微（監査）：栗が絵の下端にかかり丸が切れる・もみじが緑の葉の絵・見本のきのこに水玉があり絵のきのこは無地。
