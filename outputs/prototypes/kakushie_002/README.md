# かくし絵 試作2回目（2026-11-11・事業部長）

ng-list.md（2026-11-09「物を普通の色・形のまま置くのはNG。周りの模様・色・線に溶け込ませる」）を受けて、1枚の絵（base_small.jpg：木の皮・雲・柵の木目・こけの岩・落ち葉・川の波）で隠し方を2通り比べた。
隠す物は5つ（柿・どんぐり・もみじ・きのこ・栗）、それぞれ別の場所（木の皮・雲・柵・岩・落ち葉）。大きさは絵の幅の約7〜8%。
画像APIは2回（元の絵1回・Aの描き直し1回、すべてバッチ、約20円）。

## A：画像AIの描き直しで「周りと同じ色・線で模様の一部として」描かせる（A_screen.jpg・A_answer_screen.jpg）
- 【事実】AIは絵全体を描き直した（元の絵との差が全体に出た）。間違いさがしのように「範囲だけ貼り戻す」ことができない。
- 【事実】もみじ（柵の木目）とどんぐり（雲のふち）は、線だけで模様になじんで描かれた。柿は木の皮の上に浮き彫りの花のような形で、目立つ。栗は普通の茶色で描かれた（NGに当たる）。**きのこは描かれなかった**。
- 【意見】隠れ具合も、物の数も、位置もAI任せになり、毎回そろえるのが難しい。答えの位置も人が探して記録する必要がある。

## B：プログラムで、物の輪郭線を周りの模様と同じ色の線で重ねる（scripts/kakushie.py、B_*.jpg）
- 線の色は、その場所の模様の暗い画素の色から自動で決める。線の濃さ・太さ・切れ方・大きさ・向きを数値で決めて、初級と上級の2段階を作った（config_B.json）。
  - 初級：濃さ0.8・太さ6px・線を92%残す・大きさ等倍
  - 上級：濃さ0.7・太さ4px・線を75%残す（ところどころ切れる）・大きさ0.85倍・向きを±25°傾ける
- 【事実】5つとも必ず入り、位置・大きさ・答えの丸は answers の数値どおりに出る。画像APIは使わない（元の絵の1回だけ）。
- 【意見】初級は「すぐには見えないが、探すと見つかる」くらい。上級はかなり難しい（雲のどんぐり以外はほぼ見えない）。上級は濃さを0.8前後に上げるとよさそう。
- 【意見】線だけの形なので、物は「模様の中の線画」に見える。物らしさ（柿のへた・どんぐりのぼうし）は形の線で出している。

## 推奨（意見）
- **Bを標準にする**。理由：5つが必ず入る、位置と難しさを数値で決められる、答えの位置がずれない、画像APIの費用が元の絵1枚分（約10円）だけ。
- 難しさは、線の濃さ・切れ方・大きさの3つで調整する。CEOに初級・上級の見え方を見てもらい、ちょうどよい数値を決めたい。
- 出題画面の右側に、物の名前と形の見本（線画）を出す形にした。
