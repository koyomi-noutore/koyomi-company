# 読みの対照表（字幕の文 → 声に渡した文）

漢字が声の文に残っていたら「漢字あり」。声の文はひらがなとカタカナだけにする。

| セリフ | 字幕 | 声に渡した文 | 確認 |
|---|---|---|---|
| intro（0.3秒） | この野菜、なーんだ？虫めがねで、のぞいてみてね。 | このやさい、なーんだ？むしめがねで、のぞいてみてね。 | OK |
| tap（16.7秒） | わかったら、画面を2回タップしてね。 | わかったら、がめんを、にかいタップしてね。 | OK |
| ready（27.0秒） | わかったかな？ | わかったかな？ | OK |
| ans（30.2秒） | 正解は、かぶでした。 | せいかいは、かぶでした。 | OK |
| comment（33.9秒） | 何秒でわかったか、コメントで教えてくださいね。 | なんびょうでわかったか、コメントで、おしえてくださいね。 | OK |
| cta（38.2秒） | 左下をクリックして、ほかの問題にも挑戦してくださいね。 | ひだりしたをクリックして、ほかのもんだいにも、ちょうせんしてくださいね。 | OK |
