# かくし絵 試作4・方式③（2026-11-20・制作）

試作3（outputs/prototypes/kakushie_003/）で採用した絵（puzzle.jpg）と、AIで取った5つの位置（answers.json の box_px）をそのまま使った。物の範囲だけを、プログラムで周りになじませた試作1問。**画像APIは使っていない（費用0円）**。アップロードはしない。
プログラムは `scripts/kakushie_blend.py` の1ファイルだけ。共通のプログラムは変えていない。画面と答えの丸は `scripts/kakushie_ai.py` の関数を読むだけ。

## 結果：監査は初級・上級とも不合格。数値の調整では直らない見込みのため、ここで止めて報告する
- 重大 K4-1：ひと目で見つかる。
  - 初級は5つとも見える。上級も4つ見え、隠れたのはどんぐりだけ。
  - 色は周りに寄るが、物の外形線・陰影・へたなどの細かい線が残り、「色の薄い物の絵が重なっている」見え方になる。
- 重大 K4-2：上級に不自然な跡が出る。模様を折り返した部分が、中心へ放射状に集まる（どんぐり・栗）。きのこは、板の継ぎ目が顔のような模様になる。
- 合格した点：探せば5つとも見つかる。答えの丸は合っている。楕円の外は変わっていない。
- 詳しくは audit.md。かくし絵の差し戻しは試作3から数えて2回目。社則7章により、次に作り直す前にCEOに相談する。

## 方式（物ごとに、枠に内接する楕円の範囲だけ）
1. 色を周りに寄せる：楕円の中の色（R・G・B）の平均とばらつきを、楕円のすぐ外の輪（40px）の値に合わせる（強さ `color`）。
2. 彩度を周りに寄せる（強さ `sat`）。
3. 周りの模様を半透明で重ねる（濃さ `texture`）。
   - 模様の出どころは `texture_mode` で選ぶ。
   - "patch"：近くの同じ大きさの範囲から写す。最初に試したが、空・地面・落ち葉など別の面が入った（きのこが橙色になる、岩に赤い葉が入る）。
   - "mirror"（採用）：楕円のすぐ外（`band` 60px）の模様を、ふちで折り返して内側へ写す。別の面は入らなくなったが、中心で放射状の継ぎ目ができた（K4-2）。
4. 元の輪郭の線を少し残す：周りの明るさより `line_thr` 以上暗い画素を、割合 `line_keep` で残す。
5. 楕円のふちは `feather` px でぼかす。

## 気づき（事実と意見を分ける）
- 【事実】色・彩度・模様を寄せると、物の「色」は消える。どんぐり・栗・もみじの本来の色が消え、試作3の「普通の色で目立つ」は解消した。
- 【事実】形の手がかりは「外形線」ではなく、物の中の陰影・立体感・細かい線（柿のへた、きのこのかさのひだ）だった。これらが残る限り、ひと目で見つかる。
- 【事実】模様を写す元は、どちらの方法でも欠点が出た。近くから写すと別の面が入り、折り返すと継ぎ目が出る。
- 【意見】方式③は「描かれた物を後から消していく」作り方である。かくし絵（周りの模様が形をつくる二重の絵）にするには、物の中を周りの模様で描き直す必要があり、プログラムだけでは届きにくいと考える。
- 【意見】選択肢（CEOに判断をお願いしたい）：
  1. やめどころとして、かくし絵の開発をいったん止め、間違い探しとほかの新ジャンルに力を回す。
  2. 方式③を続ける。物の中を周りから埋める処理（inpaint）で陰影と細かい線を消し、外形線だけを周りの線の太さで描き直す。費用は0円だが、作業の量が増え、上手くいく保証はない。
  3. concept.md の方法③（Replicate のイリュージョン生成、月2,000円）に戻る。
  4. 物の大きさを5〜8%に縮めて、方式③をもう一度試す。小さい物は陰影が目立ちにくい。
