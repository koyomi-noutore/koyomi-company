## 変えた点
1. 向きの回転を ±120度（hard だけ）。字を描いた実際の形で、置くたびに重なりを検査して置く（円で近似する方法をやめた）。
2. 見出しを「ちがうのどーれだ？」に。1行に収まる最大の大きさ（約100px、幅900以内）。幕の最初の文字も同じ見出し。
3. 説明文を2行に：「一つだけ違う字があるよ。」／「見つけてみてね！」（みかんは「違うみかん」）。「大きさも向きも…」は削除。
4. 最後の流れ：答え合わせ → 「わかったら、コメントで教えてくださいね」（声＋大きな文字、約2.5秒）→ 「左下をクリック」＋矢印。
5. 最後の流れを共通の部品 scripts/short_outro.py にした（comment="text" か "find"。間違い探しは "find"＝「いくつ見つかったか、コメントで…」）。text_shorts.py・ep_short.py は変えていない（呼べる形にしただけ）。
6. 声に渡した文は wav の隣の json に残る（text_shorts.voice）。transcribe_check.py で比べた：18声すべて「渡した文」の列あり・判定 OK（transcript_check.md）。
