# 読みの対照表（字幕の文 → 声に渡した文）

漢字が声の文に残っていたら「漢字あり」。声の文はひらがなとカタカナだけにする。

## easy
| セリフ | 字幕 | 声に渡した文 | 確認 |
|---|---|---|---|
| intro（0.3秒） | 違う漢字が、1つだけあります。どれでしょう？ | ちがうかんじが、ひとつだけあります。どれでしょう？ | OK |
| tap（5.0秒） | わかったら、画面を2回タップしてくださいね。 | わかったら、がめんを、にかいタップしてくださいね。 | OK |
| ans0（20.0秒） | 答えです。 | こたえです。 | OK |
| ans1（21.5秒） | 「季節」の『季』の中に、「李（すもも）」の『李』が、混ざっていました。 | きせつの、き、のなかに、すももの、り、が、まざっていました。 | OK |
| cta（28.4秒） | 左下をクリックして、ほかの脳トレにも挑戦してくださいね。 | ひだりしたをクリックして、ほかののうトレにも、ちょうせんしてくださいね。 | OK |
