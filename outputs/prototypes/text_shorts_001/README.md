## 画面の流れ（3本共通）
1. 0〜4秒：暗い幕の上に大きな問題文（0:00 の画面がそのままサムネになる）。
2. 考える時間：①12秒・②17秒・③20秒。のこり秒数と「わかったら 画面を2回タップしてね」を出す。
3. 答え：答えを1つずつ黄色・赤で出す。
4. 最後の5秒：暗い幕の上に「答えは コメントでも 教えてね」「わかったら 画面を2回タップしてね」。

見た目：
- 書体は太い角ゴシック（Noto Sans CJK JP Black）。背景は濃い藍、カードは生成りの2色。こよみ先生は出さない。
- 文字はスマホの安全な範囲の中に置いた（左右36px・上120px・下の約2割を避ける。監査が数値で確認）。

## 確認
- **調査部（research_check.md）：** 3本とも答えは正しく、□の形で答えは1つに決まる。①の問題文の「3つ」は、ほかの は行の県（広島・福岡・福島）も正解と思われるため外した。
- **監査（audit.md）：** 3本とも合格（一発合格）。軽微のうち3つは送る前に直した。
  - ③の右の文字を、右のボタンの帯から離した。
  - ②の答えの行が、下のカードに重ならないようにした。
  - 最後の幕の文言を「…タップしてね」にそろえた。
- **残る軽微（CEOの評価で判断）：** 答えを見せた後にも「わかったら2回タップ」が出る順番。

## 気づき
- 【事実】1本の書き出しは約10秒。問題と答えを書き換えるだけで量産できる（1本あたり数分）。
- 【意見】毎日3本にするなら、問題の一覧（都道府県・ひらがな十字・似た漢字の組）を表にして、調査部がまとめて確かめる形がよい。答えが1つに決まるかの確認（とくにひらがな十字）は、辞書サイトに接続できれば機械的に全数照合できる。
- 【意見】声を付けるかどうかは、Fish Audio の残高と合わせてCEOの判断。文字だけでも成り立つ形にしてある。
