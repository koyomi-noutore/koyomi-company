## 画面の流れ（3本共通）
1. **はじめ：** 暗い幕の上に大きな問題文。0:00 から出ているので、0:00 の画面がそのままサムネになる。こよみ先生が問題を読む。
2. **考える時間：** ①12秒・②17秒・③20秒。右上に残り秒数を出す。こよみ先生が「わかったら、画面を2回タップしてくださいね」と言う。
3. **答え：** 「答えです」のあと、答えを1つずつ出し、こよみ先生が読む。
4. **最後：** 暗い幕の上に「ほかの脳トレにも 挑戦！ 左下をクリック」。間違いさがしのショートと同じ矢印で、左下の関連動画のリンクへ誘導する。声は「左下をクリックして、ほかの脳トレにも挑戦してくださいね」。

見た目：
- **こよみ先生：** 左下の余白に置き、右に吹き出しで今のセリフを出す。クイズの大きさと形は変えていない（CEO 11/21）。
- **書体と色：** 太い角ゴシック（Noto Sans CJK JP Black）。背景は濃い藍、カードは生成りの2色。
- **文字の場所：** スマホで隠れない範囲の中に置いた。左右36px・上120px・下の約2割と右のボタン（x900〜）を避け、監査が数値で確認した。
- **投稿時の設定：** ショートの関連動画（左下のリンク）には、Studio で動画を1本選んで付ける。再生リストは選べない。長尺の間違い探しか、同じ種類のショートを付ける。

## 確認
- **調査部（research_check.md）：** 3本とも答えは正しく、□の形で答えは1つに決まる。①の問題文の「3つ」は外した。広島・福岡・福島も正解だと思われるため。
- **監査（audit.md）：** 11/20版・11/21改訂版とも、3本とも一発合格。
  - 改訂版の軽微のうち2つは、送る前に直した：③の「路」の読みを「みち」から「ろ」に、②を「こたえは、かです」に。
  - 残る軽微（次の版で直す）：
    - 吹き出しの改行が言葉の途中で切れる所がある。
    - 吹き出しの字（46px）がやや小さい。
    - 最後の幕の文字の高さと色が、間違いさがしのショートと少し違う（矢印は同じ）。
