# 016 答えの一意の確かめ（よこ「み□ん」・たて「お□ゆ」→ か）　※2026-11-23 差し戻しR-1で「さかな」から「おかゆ」に変更

冬の食べ物：みかん（冬の果物）・おかゆ（七草がゆ・体のあたたまる冬の食べ物）。
辞書ツールがないため、ひらがな全部（清音・濁音・半濁音・小さい字・「ん」）を真ん中に入れて、よこ・たてそれぞれが言葉になるかを目で確かめた。
片方だけ言葉になる文字にも〇を付けて残す。答えは両方〇の文字。

## よこ「み□ん」で言葉になる（〇）
| 文字 | 言葉 | たて「お□ゆ」も言葉か |
|---|---|---|
| か | みかん | 〇 おかゆ → **答え** |
| け | みけん（眉間） | × おけゆ |
| こ | みこん（未婚） | × おこゆ |
| し | みしん（ミシン） | × おしゆ |
| ぜ | みぜん（未然） | × おぜゆ |
| と | みとん（ミトン） | × おとゆ |
| ほ | みほん（見本） | × おほゆ |
| り | みりん（味醂） | × おりゆ |
| れ | みれん（未練） | × おれゆ |

- 上の9字以外（あ行・さ行・た行・な行・は行・ま行・や行・ら行・わ・を・ん・濁音・半濁音・小さい字）は、よこが言葉にならない（例：みあん・みいん・みさん・みせん・みなん・みひん・みまん・みもん・みやん・みらん・みるん・みろん・みわん・みんん・みがん・みばん・みゃん）。「ん」は「みんん」で×。

## たて「お□ゆ」で言葉になる（〇）
| 文字 | 言葉 | よこ「み□ん」も言葉か |
|---|---|---|
| か | おかゆ（お粥） | 〇 みかん → **答え** |
| つ | おつゆ（お汁） | × みつん |
| も | おもゆ（重湯） | × みもん |

- 上の3字以外は、たてが言葉にならない（例：おあゆ（鮎は「あゆ」）・おいゆ・おさゆ・おゆゆ・おんゆ・おりゆ・おゃゆ）。「ん」は「おんゆ」で×。

## 結論
- 両方が言葉になる文字は「か」だけ（みかん・おかゆ）。答えは1つ。
