# 016 答えの一意の確かめ（よこ「み□ん」・たて「さ□な」→ か）

辞書ツールがないため、ひらがな全部（清音・濁音・半濁音・小さい字・「ん」）を真ん中に入れて、よこ・たてそれぞれが言葉になるかを目で確かめた（2026-11-23）。
片方だけ言葉になる文字も〇を付けて残す。答えは両方〇の文字。

## よこ「み□ん」で言葉になる（〇）
| 文字 | 言葉 | たて「さ□な」も言葉か |
|---|---|---|
| か | みかん | 〇 さかな → **答え** |
| け | みけん（眉間） | × さけな |
| こ | みこん（未婚） | × さこな |
| し | みしん（ミシン） | × さしな |
| ぜ | みぜん（未然） | × さぜな |
| と | みとん（ミトン） | × さとな |
| ほ | みほん（見本） | × さほな |
| り | みりん（味醂） | × さりな（人名のみ） |
| れ | みれん（未練） | × されな |

- 上の9字以外（あ行・さ行・た行・な行・は行・ま行・や行・ら行・わ・を・ん・濁音・半濁音・小さい字）は、よこが言葉にならない（例：みあん・みいん・みさん・みせん・みなん・みひん・みまん・みもん・みやん・みらん・みるん・みろん・みわん・みんん・みがん・みばん・みゃん）。「ん」は「みんん」で×。

## たて「さ□な」で言葉になる（〇）
- か＝さかな（魚）だけ。さあな・さいな・さえな・さきな・さくな・ささな・さしな・さつな・さとな・さなな・さまな・さらな・さんな など、ほかは全部 ×（「さんな」「さらな」は単独の言葉として扱わない）。「ん」は「さんな」で×。

## 結論
- 両方が言葉になる文字は「か」だけ（みかん・さかな）。答えは1つ。
