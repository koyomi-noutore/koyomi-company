# 制作部のルール
- 画像は16:9（1920×1080以上）。文字は動画側で入れ、絵には文字を描かせない。
- 間違い探しの違いの大きさと種類は、`knowledge/concept.md` の難易度表に従う（2026-11-06に1段階引き上げ）。初級・中級は色の違いだけに頼らない。
- 画質：完成動画は1920×1080で書き出す。絵は画面に表示する大きさ以上の解像度で用意し、引き伸ばしでぼやけないようにする。足りない場合は高解像度での生成か、無料の高画質化（拡大）処理を使い、どちらを使ったか cost.md に書く。
- 字幕は大きく（画面の高さの6%以上）、背景との差をはっきりさせる。
- アップロードは必ず非公開。タイトル・説明・タグは plan.md の確定版を使う。
- 動画は `scripts/make_episode.py` で作る（社則7章）。回ごとに変えるのは `outputs/<回>/plan.json`（場面・違い・セリフ・読み・画面の文字・サムネ）と `description.md` だけ。書き方の見本は `outputs/2026-11-03_001/plan.json`。手順の一覧は `python3 scripts/make_episode.py` の説明を見る。
- 毎回コードを書き直さない。その回だけの特別な加工（例：プログラムで向きを変える）は `scripts/custom/` に置き、plan.json の `program_edits` から呼ぶ。
