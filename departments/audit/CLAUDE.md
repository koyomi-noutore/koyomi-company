# 品質監査のチェックリスト

## 事実と表現
- [ ] うんちく・季節の事実に出典があり、内容が正しい
- [ ] 医学的な効果をうたっていない
- [ ] 誤字脱字がない。漢字の読み問題の答えが正しい

## わかりやすさ（シニア目線）
- [ ] 各問題のルール説明が5秒以内で、絵を見ればわかる
- [ ] 字幕が大きく読みやすい。話す速さがゆっくり
- [ ] 間違い探しの違いが見つけられる大きさで、答えの位置が正しい
- [ ] 意図しない違い（描き直し以外の差）がない
- [ ] **消した物の一部が残っていない**（2026-11-14 CEO指摘：干し柿のひも・さんまの尾など、消し残りの切れ端は違和感が強い）。消した範囲の周りを拡大して、輪郭の切れ端・影・ひもが残っていないか必ず見る
- [ ] **（2026-11-20 CEO指摘・最低品質6）絵全体に明らかにおかしい物がない**：宙に浮いている物（台の脚が地面・床に着いていない太鼓など）、支えのない物、絵の中の文字。違いの範囲だけでなく、5問の絵の全体を一覧画像で1枚ずつ見る（飛んでいる鳥・虫は別）
- [ ] 3つの違いが絵全体に散らばっていて、1つ見つけると他もすぐ見つかる配置になっていない

## チャンネルの約束
- [ ] 構成が concept.md の間違い探し回の構成（5問・約10分）に沿っている
- [ ] 出題中・答え合わせ中は絵が画面いっぱいで、キャラの絵が出ていない
- [ ] オープニング・うんちく・エンディングにこよみ先生が登場し、色・表情が character.md どおり
- [ ] 絵が引き伸ばしでぼやけていない（1080pで見て細部がはっきりしている）
- [ ] 違いの大きさと種類が難易度表どおり（易しすぎない）
- [ ] 合いの手が多すぎて邪魔になっていない

## サムネイルとタイトル
- [ ] タイトルで同じ言葉を2回使っていない。サムネの文字は意味のまとまりで色分けされている
- [ ] サムネが設定されている（自動生成のままではない）
- [ ] サムネ・タイトルの内容（問題数・難易度・テーマ）が動画と一致している
- [ ] スマホの小さな表示で文字が読める
- [ ] 競合の絵・キャラ・ロゴ・言い回しをそのまま使っていない

## 規定・権利
- [ ] 前の回と、テーマ・場面・うんちくが重複していない（量産型と見なされない）
- [ ] 他人の著作物・実在の人物の声を使っていない
- [ ] タイトル・説明文に誇大な表現や誤解を招く表現がない

## 2026-11-25 CEO決定で重大にする項目
- 上級（第5問）の違いの大きさが4.0%を超える（check.json の blocking に出る。check で止まるので、ここまで来たら重大）。
- 同じ物・同じ変化が1回の動画の中で2度以上出る（label が違っても、物が同じなら重大）。
- 参考：アップロード済みのショートで答えのあいだが0.34〜0.37秒だった件は、CEO判断で「問題なし」（11/25）。新しく作る回は今までどおり0.4秒以上。
