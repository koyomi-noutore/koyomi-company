# 品質監査のチェックリスト

## 事実と表現
- [ ] うんちく・季節の事実に出典があり、内容が正しい
- [ ] 医学的な効果をうたっていない
- [ ] 誤字脱字がない。漢字の読み問題の答えが正しい

## わかりやすさ（シニア目線）
- [ ] 各問題のルール説明が5秒以内で、絵を見ればわかる
- [ ] 字幕が大きく読みやすい。話す速さがゆっくり
- [ ] 間違い探しの違いが見つけられる大きさで、答えの位置が正しい
- [ ] 意図しない違い（描き直し以外の差）がない

## チャンネルの約束
- [ ] 構成が concept.md の間違い探し回の構成（5問・約10分）に沿っている
- [ ] 出題中・答え合わせ中は絵が画面いっぱいで、キャラの絵が出ていない
- [ ] オープニング・うんちく・エンディングにこよみ先生が登場し、色・表情が character.md どおり
- [ ] 絵が引き伸ばしでぼやけていない（1080pで見て細部がはっきりしている）
- [ ] 違いの大きさと種類が難易度表どおり（易しすぎない）
- [ ] 合いの手が多すぎて邪魔になっていない

## 規定・権利
- [ ] 前の回と、テーマ・場面・うんちくが重複していない（量産型と見なされない）
- [ ] 他人の著作物・実在の人物の声を使っていない
- [ ] タイトル・説明文に誇大な表現や誤解を招く表現がない
