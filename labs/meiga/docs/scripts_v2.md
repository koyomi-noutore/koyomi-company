# 名画ショート 台本 v2（2026-11-28）

## v1へのレビュー（Ichiro・11/28）
- ゴッホは**台本1（疑似体験型）が一番良い**。ただしフック「今から60秒だけ、あなたはゴッホです」は**絶対に弱い**。新しいフックを試行錯誤する。
- ナレーションは**主語と述語をしっかり**。きれいな日本語を土台にし、その上にチャンネルの語り口調を乗せる。
  - 例：「1888年。あなたはオランダ人の画家。35歳。」は区切れすぎでは。
- エピソードは強くて面白いが、**点で唐突に投げられている**。一本の線・面でつながっていない（ストーリーテリングの問題）。
- ムンクのフック（叫んでいるのは誰だと思いますか）は良さそう。北斎のフック（この舟に乗ってもらいます）も良い。
- 北斎の「全46枚の富士山シリーズの1枚」をさらっと言うのはもったいない。**「三十六景なのに46枚」は、へーと思わせる最高のうんちく。** ベロ藍の話も、もっと広げてよい。
- エピソードは詰め込まない。**1本の動画では、狙って伝えたいエピソードを少数選び、深く広げる。** 画家の絵はたくさんあるので（北斎なら36〜46枚）、1本で全部語る必要はない。

## 文章のルール（ナレーションの土台）
耳で聞く文章は読み返せない。だから、書き言葉以上に「一度で分かる」ことを優先する。

### 土台：きれいな日本語
1. **主語と述語を近づける。** 間に長い説明をはさまない。説明が長いときは、文を分ける。
2. **1つの文には、主語と述語を1組。** 「〜して、〜したので、〜だが」とつなげない。
3. **修飾する言葉は、修飾される言葉の直前に置く。** 長い修飾を先に、短い修飾を後に。
4. **一文は短く。ただし、ぶつ切りにしない。** 目安は1文20〜40字。単語だけの文（「35歳。」）を並べない。
5. **体言止めは、ここぞという1か所だけ。** 続けると情報の羅列に聞こえ、文と文がつながらない。
6. **文と文を、つなぎの言葉で結ぶ。** 「ところが」「だから」「そして」「けれども」。これが話を点から線にする。
7. **耳で分かる言葉を選ぶ。** 同音異義語や硬い漢語は、やさしい言い方に変える（例：療養院 → 字幕では「療養院」、声は「病院」でもよい）。
8. **「これ」「それ」を減らす。** 指すものが映像に映っているときだけ使う。

### 物語のルール（点を線にする）
1. **1本に問いを1つ。** 冒頭で問いを立て（または謎を予告し）、すべての場面がその答えに向かって進む。最後に答えを渡す。
2. **エピソードは2〜3個に絞る。** 1つの場面に事実を1つ。選ぶ基準は「問いの答えに必要か」。
3. **場面と場面は「なぜなら」「ところが」でつなぐ。** 時系列に並べるだけにしない。前の場面が、次の場面の理由や前ぶりになるようにする。
4. **一番の「へー」は、最後から2番目に置く。** 最後の一文は余韻（見え方が変わる一言）にする。
5. **締めは黒く消すのではなく、本物の絵に戻る。** 戻った絵が、冒頭とは違って見えることがゴール。

### チャンネルの語り口（仮）
- です・ます調。落ち着いた美術館のガイドの声。
- 疑似体験の場面では「あなた」を主語にしてよい。本物の絵に戻る瞬間に、視点も「あなた」から外へ戻す。
- 長さの目安：1分間に約300字。60秒の動画なら約280〜320字。
