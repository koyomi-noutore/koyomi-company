# 名画ショート 台本 v1（2026-11-28）

W1（星月夜の一人称の世界）へのレビューを受けて書いた台本5本。
- レビュー：映像は斬新で没入感もあるが、**その後を見る理由がない**。「これがゴッホの見た夜でした、ちゃんちゃん」で終わっている。終わり方も雑。
- 必要なもの：**名画ごとのコンテキスト**。なぜ画家にはそう見えたのか（言われている説）、どこの景色か、画家はどこの何人で、そのとき人生のどこにいたか。見る側の得は「名画・画家に詳しくなる」「うんちくが増える」「その人の人生を疑似体験する」。

## 5本の共通ルール
- 長さ：50〜60秒（ナレーション約270〜330字）。一人称の映像は8秒の場面×6〜7つ。
- 0〜6秒：H4型のフック（1コマ目からいきなり絵に落ちる＋誘い）。言葉だけ台本ごとに変える。
- 3〜10秒以内に「この先で分かること（見返り）」を予告し、すぐには答えない（理論の原理M）。
- 1場面につき新しい事実を1つ。うんちくが場面ごとに積み上がるようにする。
- 終わり方は3つから選ぶ：①最後のひと言で見え方がひっくり返る ②最初の絵に戻って「もう一度見ると違って見える」 ③次回の画家への誘い（シリーズの型）。黒く消えて終わりにはしない。
- 事実は定説・逸話・本人の手紙を使う（ショートでは厳密な確認はしない。11/27の方針）。
- 各台本の最後に「この台本で確かめたいこと」を書いた。

## 台本1　星月夜「あなたはゴッホ」（疑似体験型）
狙い：視聴者がゴッホ本人になり、この絵を描くまでの1年を一人称で生きる。人生の疑似体験。

| 秒 | 映像（一人称） | ナレーション |
|---|---|---|
| 0〜6 | 《星月夜》に、いきなり落ちていく → 白 | 今から60秒だけ、あなたはゴッホです。 |
| 6〜14 | 白の中で目を開く。南フランスの麦畑、まぶしい黄色い太陽。自分の絵の具だらけの手 | 1888年。あなたはオランダ人の画家。35歳。絵は、ほとんど売れたことがない。明るい光を求めて、南フランスのアルルに来た。 |
| 14〜22 | 黄色い家。向かいに座る男（ゴーギャンの後ろ姿）。言い争い、皿が割れる | 画家仲間ゴーギャンを呼んで、夢の共同生活。でも2か月で大げんか。 |
| 22〜30 | 鏡の中の自分。左耳の包帯（血は見せない） | その夜、あなたは自分の耳を切り落とした。 |
| 30〜38 | 療養院の部屋。鉄格子の窓。外はまだ暗い | 翌年の春、あなたは自分から療養院に入る。窓には鉄格子。 |
| 38〜48 | 窓へ近づく → 夜明け前の空に、大きく光る星 | 弟への手紙に、あなたは書いた。「今朝、日の出のずっと前に窓から外を見た。明けの明星だけが、とても大きく見えた」 |
| 48〜58 | 窓を抜け、空が渦を巻き始める → 本物の《星月夜》に戻る | その空を、あなたは記憶で描いた。この絵です。あなたはこれを「失敗作」と呼び、1年後に37歳で亡くなる。 |
| 58〜60 | 絵の上に文字だけ | 今は、ニューヨークで世界一有名な夜空になっています。 |

終わり方：①ひっくり返る（本人は失敗作と呼んだ → 今は世界一有名）。
この台本で確かめたいこと：「あなたは〇〇です」の二人称で、人生の疑似体験が最後まで引っぱるか。

## 台本2　星月夜「空はなぜ渦を巻くのか」（謎解き型）
狙い：1つの謎に、説を3つ順に出す。最後に一番意外な説を置く。

| 秒 | 映像（一人称） | ナレーション |
|---|---|---|
| 0〜6 | 《星月夜》に落ちていく → 白 | ゴッホの夜空は、なぜ渦を巻いているのか。中に入って確かめます。 |
| 6〜14 | 療養院の窓から見る、静かで普通の星空 | 1889年、南フランス。ゴッホが療養院の窓から見ていた本当の夜空は、こんなふうに静かでした。 |
| 14〜24 | 空がゆっくり揺れ始める。視界が少しゆがむ | 説その1。心の病。ゴッホは発作に苦しんでいて、世界がこう見えていたのでは、という説。 |
| 24〜34 | 星の光が黄色くにじむ。テーブルの薬瓶 | 説その2。薬。当時の治療薬ジギタリスには、ものが黄色く、光の輪をまとって見える副作用がある。だから星に光の輪が、という説。 |
| 34〜46 | 渦が大きくうねり、川の流れや雲の渦と重なる | 説その3。物理学者が絵の渦を測ると、本物の空気や水の乱れ、「乱流」と同じ法則になっていた。しかも、心が一番乱れていた時期の絵ほど、その法則に近い。 |
| 46〜56 | 渦の中心へ吸い込まれる → 本物の《星月夜》に戻る | ゴッホは、目に見えない空気の流れを、科学より先に描いていたのかもしれません。 |
| 56〜60 | 絵の上に文字 | もう一度、空を見てください。 |

終わり方：②最初の絵に戻って、見え方が変わる。
この台本で確かめたいこと：謎→説を3つの「答えを少しずつ出す」構成で、最後まで残るか。科学の説が「うんちく」として刺さるか。

## 台本3　星月夜「失敗作と呼ばれた絵」（人生の一夜型）
狙い：療養院の一夜だけを描き、そこに人生と絵の秘密を詰める。場面数が少なく作りやすい。

| 秒 | 映像（一人称） | ナレーション |
|---|---|---|
| 0〜6 | 《星月夜》に落ちていく → 白 | この絵を描いた本人は、これを「失敗作」と言いました。 |
| 6〜16 | 夜の療養院の廊下。ろうそく。遠くで誰かのうめき声 | 1889年、南フランスのサン＝レミ。耳を切る事件のあと、ゴッホは自分からこの療養院に入りました。 |
| 16〜26 | 小さな部屋。描きかけのキャンバス、絵の具。鉄格子の窓 | 夜は部屋で絵を描けない。だからこの夜空は、窓から見た景色を覚えておいて、昼間に描いたものです。 |
| 26〜36 | 窓の外の村をよく見る。教会の尖った塔 | よく見ると、村の教会はフランスの形ではなく、故郷オランダの教会の形。ホームシックだった、という説があります。 |
| 36〜46 | 手前の大きな糸杉を見上げる | 左の黒い炎のような木は糸杉。墓地に植えられる、死の象徴の木です。 |
| 46〜56 | 窓から空へ。渦が回り始める → 本物の《星月夜》 | 生と死、故郷と異国。弟への手紙では、星を大きく描きすぎた失敗だと書いています。翌年、ゴッホは37歳で亡くなりました。 |
| 56〜60 | 絵の上に文字 | 次は、ゴッホが憧れた日本の画家、北斎の波の中へ。 |

終わり方：③次回への誘い（ゴッホは北斎を尊敬していた → 北斎回へつなぐ）。
この台本で確かめたいこと：「絵の中の細部の秘密」（教会・糸杉）を一人称で見つけていく形が面白いか。次回予告の終わり方。

## 台本4　ムンク《叫び》「叫んでいるのは誰か」（謎解き＋見え方の逆転）
狙い：誰もが知っている顔の絵の「思い込み」をひっくり返す。

| 秒 | 映像（一人称） | ナレーション |
|---|---|---|
| 0〜6 | 《叫び》に落ちていく → 白 | この絵、叫んでいるのは誰だと思いますか。中に入ってみます。 |
| 6〜16 | 夕暮れのオスロの丘の道。友人2人の後ろ姿。フィヨルドと街 | 1892年、ノルウェーのオスロ。画家ムンクは、友人2人と夕暮れの道を歩いていました。 |
| 16〜26 | 空が急に血のように赤くなる。体が止まる | 突然、空が血のように赤く染まった。友人たちは先に行ってしまう。ムンクは不安でふるえ、立ち止まった。 |
| 26〜36 | 耳をふさぐ自分の両手。景色全体が波打つ | そして、自然をつらぬく、終わりのない叫びを聞いた。日記にそう書いています。つまり、叫んでいるのは人ではなく自然。この人は、耳をふさいでいるんです。 |
| 36〜46 | 道の先に建物（精神病院）が見える | この丘のふもとには精神病院があり、ムンクの妹が入院していたとも言われています。5歳で母を、14歳で姉を亡くした人でした。 |
| 46〜56 | 赤い空が火山の噴煙の夕焼けと重なる → 本物の《叫び》 | 赤い空は、遠いインドネシアの火山の大噴火で世界中の夕焼けが赤くなったのを覚えていたから、という説もあります。 |
| 56〜60 | 絵の隅に寄る。鉛筆の小さな文字 | そしてこの絵の隅には、小さな落書きがあります。「狂った男にしか描けない」。書いたのは、ムンク本人でした。 |

終わり方：①ひっくり返る（最後に落書きの秘密）。
この台本で確かめたいこと：思い込みの逆転（叫んでいるのは自然）＋最後の一撃で、コメントや保存が生まれそうか。

## 台本5　北斎《神奈川沖浪裏》「あなたは舟の上」（疑似体験＋人物の面白さ）
狙い：W1と同じ一人称の疑似体験を、日本の絵で。北斎という人物の面白さを足す。

| 秒 | 映像（一人称） | ナレーション |
|---|---|---|
| 0〜6 | 《神奈川沖浪裏》に落ちていく → 白 | 今から、この舟に乗ってもらいます。 |
| 6〜14 | 細い舟の上。必死に櫂をこぐ男たち。舟には魚 | 江戸時代。あなたは押送船（おしおくりぶね）の漕ぎ手。とれたての魚を江戸の市場へ、誰より早く運ぶのが仕事です。 |
| 14〜24 | 正面に巨大な波が立ち上がる。見上げる | 目の前に、山のような大波。波の先は、獲物をつかむ爪のように割れている。 |
| 24〜32 | 波の向こう、ずっと小さく白い富士山 | その奥に、小さな富士山。この絵の本当の主役は、波ではなく富士山です。全46枚の富士山のシリーズの1枚。 |
| 32〜42 | 波に飲み込まれる直前、深い青に包まれる | この青は、ヨーロッパから入ってきたばかりの新しい絵の具「ベロ藍」。描いたとき、北斎は70歳を過ぎていました。 |
| 42〜52 | 青の中から、北斎の小さな仕事部屋。散らかった部屋 | 北斎は引っ越し93回、名前を変えること30回。部屋が汚れたら引っ越した、という人です。 |
| 52〜60 | 本物の《神奈川沖浪裏》に戻る | 90歳で亡くなる前の言葉は「あと5年あれば、本物の絵描きになれたのに」。この波は、のちにゴッホも夢中にさせました。 |

終わり方：①ひっくり返る（あの北斎がまだ満足していなかった）＋③ゴッホとのつながり。
この台本で確かめたいこと：日本の絵・日本人の画家で、名前を知っている程度の人にも刺さるか。人物の面白い逸話が見続ける理由になるか。
