# 名画ショート 台本 v3（2026-11-28）

土台：`docs/scripts_v2.md` の文章のルール、`knowledge/shorts_theory.md`（ショートの一般則）、`knowledge/yomi.tsv`（読み辞書）。

## v2へのレビュー（Ichiro・11/28）
### ゴッホ
- フックの順位：**B・C・E ＞ F・A ＞＞ D**。
- 良い点：ストーリー仕立て。読みやすく、頭に入る。地名（フランス）が出ると情景が浮かぶ。耳の話で引き込まれる。
- **最後に「あなた」から「ゴッホ」に戻す形は良い。** 絵に戻ってループもできる。ショートではループが大事。
- 直したい点：
  - 冒頭の「あなたはオランダの画家です。暗い故郷を離れ」に、もう少しバックストーリーが欲しい。
  - 「光を求めて来たあなたに残ったのは…」は良い文。ただ「皮肉なことに」のような、文脈を理解させるひと言が適宜あるとよい（毎回だとうるさいので、ここぞで）。
  - 締め：「失敗作と考えていました」のあとに、「けれども今では世界で最も…」のどんでん返しが作れる。「光を求めて南へ来た画家がたどり着いたのは、鉄格子越しの夜空」もパンチが強くて良い。
### 北斎
- フックの順位：**A ＞ C ＞ B ＞＞ D**。「今から、この舟に乗ってもらいます」は面白い。ただし、効くのは**その絵を一度でも見たことがある場合**。神奈川沖浪裏は誰でも見たことがあるので大丈夫。絵の知名度に合わせてフックを選ぶ必要がある。
- 「三十六景なのに46枚」は神奈川沖浪裏の回では使ってよい（例外）。ただし残りの45枚では使えないので、絵ごとに切り口を用意する必要がある。
- 「大波がそびえ立つ」は情景的で良い。「小さな富士山」より「大きな富士山が小さく見えています」のほうが正確。
- ベロ藍は面白い。「人々の目を引いたのはこの青でした」も良い。
- **文脈が飛ぶ問題**：「当時の江戸は富士山に登ることが大流行していました。シリーズは大当たりし…」は、流行の話から増刷の話へ同じ場面で飛び、混乱する。話題が変わるときはクッションか場面の切り替えが要る。**ぼーっとリールを眺めている人でも頭に入る**分かりやすさが必要。
- 締めの「ゴッホも弟への手紙で絶賛」は知識として面白く、ゴッホ回とつながる。過去に扱った画家の名前を出すのは（毎回でなくても）チャンネルとして強い。
- 質問：ヨーロッパ人が驚いたのは北斎の波の描き方では？
### ムンク
- フックはもっと良くなる。
- 「この人」は誰なのか（ムンクなのか、分かっていないのか）が曖昧。ムンクだと言われているならそう言う。
- 鉛筆の小さな文字の話は面白い。全体に簡潔で良い。
### 共通
- ナレーションを音声合成で読ませるとき、漢字の読み（音読み・訓読み、複数の読み）を制御する。→ 読み辞書と確認スクリプトを用意した（`knowledge/yomi.tsv`、`scripts/yomi.py`）。無料の音声で試すと「押送船」を「オーソーセン」、「柵」を「シガラミ」と誤読した。
- ショートの一般則（ループ、勝ちパターン）を日本語・英語で調べた → `knowledge/shorts_theory.md`。

## ゴッホ《星月夜》v3
**問い**：この夜空は、どこから見た景色なのか。（フックB）
**線**：遅れて画家になり、弟に支えられる → 光を求めて南へ → 夢が壊れる → 皮肉にも鉄格子の窓だけが残る → その窓から見た星を、弟への手紙に書く → 記憶で描く → 本人は失敗作 → 今は世界で最も愛される夜空 → 答え：鉄格子越しの夜空。
**伏線**：冒頭で「弟テオの仕送り」を出し、後半の「弟への手紙」で回収する。
**ループ**：最後は本物の《星月夜》で終わる＝冒頭の1コマ目と同じ絵。最後の一文が、冒頭の問い「どこから見た景色か」の答えになる。

| 13〜20 | 列車の窓から、まぶしい南フランスの麦畑と太陽 | 35歳のとき、あなたはもっと明るい光を求めて、南フランスのアルルへ移ります。 |

## 北斎《神奈川沖浪裏》v3
**問い**：「三十六景」なのに、なぜ46枚あるのか。（3場面目で立てる）
**線**：舟の上で大波に出会う → 奥に富士山 → シリーズ名の謎を出す → 江戸の町へ移って理由を探す：①富士山ブーム ②新しい青 → だから大ヒット → だから10枚追加 → 波はヨーロッパへ。
**直したところ**：流行の話と追加の話を別の場面に分け、間に「その理由を知るために、江戸の町へ」という場面の切り替えを入れた。理由①②を並べてから、「だから」で結論へつなぐ。
**ループ**：最後は本物の絵 → 冒頭の「この舟に乗ってもらいます」へ。

| 秒 | 映像（一人称） | ナレーション |
|---|---|---|
| 0〜4 | 《神奈川沖浪裏》に落ちていく → 白 | 今から、この舟に乗ってもらいます。 |
| 4〜12 | 細い舟の上。必死にこぐ男たち。舟には魚 | 舞台は江戸時代の海。あなたが乗っているのは、とれたての魚を江戸へ運ぶ、押送船という速い舟です。 |
| 12〜19 | 正面に巨大な波がそびえ立つ。見上げる。波の奥に富士山 | 目の前に、山のような大波がそびえ立ちます。そして波の向こうには、あの大きな富士山が、小さく見えています。 |
| 19〜29 | 時間が止まり、富士山へ寄る | この絵は、富士山をさまざまな場所から描いたシリーズ、「富嶽三十六景」の1枚です。ところがこのシリーズ、名前は三十六景なのに、実は46枚あるのです。 |
| 29〜38 | 白へ抜け、江戸の町。遠くに富士山。白装束で富士山へ向かう人々 | その理由を知るために、当時の江戸の町へ行ってみましょう。このころの江戸では、富士山に登ることが大流行していました。 |
| 38〜49 | 版元の店先。並んだ版画の、鮮やかな青 | そこへ売り出されたのが、北斎の富士山の絵です。人々の目を引いたのは、この青でした。ヨーロッパで生まれた新しい絵の具で、「ベルリンの藍」を縮めて、「ベロ藍」と呼ばれました。 |
| 49〜58 | 人だかり。絵が次々と売れていく | 憧れの富士山と、見たことのない青。だから絵は飛ぶように売れました。そこで、36枚で終わるはずだったシリーズに、10枚が付け足されたのです。 |
| 58〜66 | 本物の絵に戻る → 冒頭の1コマ目へ | 描いたとき、北斎は70歳を過ぎていました。そしてこの青い波は海を越え、のちにゴッホも、弟への手紙で絶賛することになります。 |

約400字・約78秒。長いので、試作のあとに削る候補：理由①の「富士山に登る大流行」の場面を短くする、締めの「70歳」を外す。

### ご質問への答え：ヨーロッパ人が驚いたのは？
そのとおりで、ヨーロッパの画家が強く驚いたのは**波の描き方と構図**です。大きな波が爪のように砕ける形、手前の大波と奥の小さな富士山の極端な遠近、平らな色面などが新しく見えました。ゴッホは弟への手紙でこの波を絶賛し、作曲家ドビュッシーは交響詩『海』の楽譜の表紙にこの波を使っています。青（ベロ藍）の話は、主に日本の中で売れた理由です。
→ 別の回の切り口に使える：「ヨーロッパを驚かせた波の描き方」。

### 46枚を1枚ずつ扱うときの切り口の作り方（メモ）
「三十六景なのに46枚」は神奈川沖浪裏の回だけで使う。他の回は、その絵だけの秘密から切り口を作る。例：
- 《凱風快晴》（赤富士）：なぜ富士山が赤いのか。
- 《山下白雨》：山のふもとに稲妻。
- 《諸人登山》：シリーズで唯一、富士山の形が描かれていない絵。
- 裏富士の10枚：追加された10枚は何が違うのか。
フックは、絵の知名度で選ぶ。誰でも知っている絵は「誘い（この舟に乗ってもらいます）」、知名度が低い絵は「問い（なぜ富士山が赤いか知っていますか）」。

## ムンク《叫び》v3
**問い**：この人は、叫んでいるのか。
**直したところ**：「この人」が誰かを明確にした。描かれた人物は**ムンク自身だと考えられている**（ムンクが日記に書いた自分の体験を描いた絵のため）。
**ループ**：最後は本物の絵 → 冒頭へ。

| 秒 | 映像（一人称） | ナレーション |
|---|---|---|
| 0〜4 | 《叫び》に落ちていく → 白 | （フック候補から選ぶ） |
| 4〜12 | 夕暮れの坂道。前を歩く友人2人。眼下にフィヨルドと街 | 1892年、ノルウェー。画家のムンクは、友人2人と夕暮れの坂道を歩いていました。 |
| 12〜22 | 空がじわじわと赤く染まる。足が止まる | ふと見ると、空が血のように赤く染まっていました。ムンクは疲れを感じて立ち止まり、柵にもたれます。友人たちは、そのまま先へ歩いていきました。 |
| 22〜31 | 景色全体が波打つ。低い響き。両手で耳をふさぐ | そのとき彼は、自然をつらぬく、果てしない叫びを聞いたと日記に書いています。 |
| 31〜41 | 本物の《叫び》に戻る。人物の手に寄る | この絵の人物は、そのときのムンク自身だと考えられています。つまり、叫んでいるのはムンクではありません。叫んでいたのは自然で、ムンクはその声に、耳をふさいでいるのです。 |
| 41〜53 | 絵の左上の隅へ寄る。鉛筆の小さな文字 | そしてこの絵の隅には、鉛筆で書かれた小さな文字があります。「狂った男にしか描けない」。長いあいだ、誰かのいたずら書きだと思われてきました。ところが近年の調べで、書いたのはムンク本人だと分かったのです。 |
| 53〜58 | 絵全体に引く → 冒頭へ | 自分の心の叫びを、ムンクは誰よりもよく知っていたのかもしれません。 |

約340字・約62秒。

### フックの候補
| 案 | フックの一文 | 型 |
|---|---|---|
| A | この絵、叫んでいるのは誰だと思いますか。 | 問いかけ（v2のまま） |
| B | ムンクの《叫び》。実はこの人、叫んでいません。 | 意外な事実（名前を先に出す） |
| C | 《叫び》の隅に、小さな落書きがあるのを知っていますか。 | 問いかけ（最後の秘密を予告） |
| D | この絵の隅には、画家本人の落書きが残っています。 | 意外な事実（最後の秘密を予告） |
| E | この人が両手で押さえているのは、顔ではなく耳です。 | 意外な事実（絵の細部） |
C・Dにする場合は、冒頭の問いの答えが「落書き」になるので、落書きの場面を最後に置き、締めの一文をその余韻にする（今の順番のままでよい）。
