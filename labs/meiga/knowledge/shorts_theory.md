# ショートの一般則（2026-11-28 調査、日本語・英語の資料から）

名画ショートの台本と編集は、ここに書いた一般則を土台にする。出典は末尾。
注意：YouTubeはおすすめの仕組みを詳しく公開していない。数字（〜%など）は各社・個人の分析で、公式ではない。傾向として使い、最後は自分たちの数字で確かめる。

## 1. ショートはどう評価されるか
- **選ばれて見られるのではなく、流れてきて見られる。** 長尺は視聴者がタップして選ぶが、ショートはフィードで勝手に流れてくる（YouTubeのショート責任者の説明）。だから「見るか、スワイプするか」が最初の審査になる。
- **まず小さな集団で試され、反応が良いと広げられる。** 最初の集団で維持率が低い・スワイプが多いと、そこで配信が止まる。
- **見る数字は2つ：①「視聴された／スワイプされた」の割合、②平均視聴時間（視聴率）。** Studioの「リーチ」タブと「エンゲージメント」タブで見られる。
- **ループ（見終わってそのまま最初から見直されること）は強い好材料。** 「1回では足りなかった」というしるしとして扱われる、と言われる。
- 2025年3月31日から、ショートの「視聴回数」は再生が始まるたび・ループするたびに数えるようになった。収益化や条件に使うのは、従来の基準の「エンゲージビュー」。判断はエンゲージビューで行う。
- 視聴者の層をそろえる。毎回違う層に向けると、YouTubeが「誰に見せればよいか」を毎回探し直すことになる。→ 名画チャンネルとして層を固定する。

## 2. 冒頭（フック）：0〜3秒
- スワイプのほとんどは最初の1〜2秒で起きる。あいさつ、ロゴ、ゆっくりしたパン、前置きは入れない。
- 一番安定している型は**好奇心の空白（curiosity gap）**：答えを知りたくなる問いや、予想を裏切る事実を出し、答えはまだ渡さない。
- **画のズレ（目を引く1コマ目）と、言葉の空白を重ねる**と強い。→ 名画ショートでは「H4：いきなり絵に落ちる映像」＋「問い・誘い」。
- **知らない人にも分かる問いでなければ、空白は開かない。** 「絵を一度見たことがある」程度の人が分かる言葉にする（Ichiroの指摘とも一致）。
- **全部を隠しすぎない。** 「何についての動画か」は1秒で分かるようにする。隠すのは答えだけ。
- 字幕は必須。音を消して見る人が多い。
- フックの改善は、本編を同じにして冒頭だけを変えたA/Bで行う。

## 3. 本編：見続ける理由
- **1本に1つの主張（問い）と、1つの盛り上がりの道筋、1つの答え。** 前置きを入れる余地はない。どの文も次の文へ引っぱる。
- **途中で小さな問いを開いて、後で閉じる（オープンループ）。** 「ところが」「なぜでしょうか」で、次の場面を見る理由を作る。
- **3〜4つの話の流れ（起承転結に近い）。** 1分以内では結論を言って終わりになりやすいが、3分まで使えれば「問題提起→展開→解決→まとめ」が作れる。名画は物語なので、60〜90秒で起承転結を作る。
- 間（無音）、言いよどみ、同じことの言い直しは、そのたびにスワイプの理由になる。
- 物語の型の例：「主人公に目的がある → しかし障害がある → だからこうした」（But / Therefore）。場面を「そして」でなく「しかし」「だから」でつなぐと、話が前に進む。

## 4. 終わり方
- **冒頭の問いに、はっきり答えて終わる。** 台本の中盤が長くなると、締めが削られやすい。締めは最初に決めておく。
- **答えのあとに、まとめ直しの一文を足さない。** 答え（または最後の一言）で終わる。
- 「フォローしてね」「続きは長尺で」を毎回言うと、維持率が落ちやすい。ショート単体で価値を完結させる。
- **ループ：最後が最初に自然につながるようにする。**
  - 画のループ：最後のコマと最初のコマをそろえる（名画ショートでは、本物の絵に戻って終わる＝冒頭と同じ絵）。
  - 言葉のループ：最後の一文が、冒頭の一文の答え・続きになる。「最後の一文と最初の一文をつなげて読んでも不自然でないか」を確認する。
  - 物語のループ：最後で、冒頭の見え方が変わる（同じ絵が、2回目は違って見える）。
- 終わりの確認：①最後の一文は冒頭の問いに答えているか ②その一文を友だちに話せるか ③最後の一文から最初の一文へつないでも不自然でないか。

## 5. 長さ
- 長さより「最後まで見られる割合」。20秒で最後まで見られる動画は、半分で離れられる60秒の動画に勝つ。
- ショートは最大3分まで投稿できる。ただし、使うのは話に必要な時間だけ。
- 名画ショートの当面の目安：60〜75秒（ナレーション約300〜370字）。試作の数字を見て調整する。

## 6. 名画ショートへの当てはめ（決まりごと）
1. 1コマ目は名画そのもの＋H4（いきなり落ちる）。言葉は問い・誘い・意外な事実から、絵の知名度に合わせて選ぶ。
2. 3〜10秒で「この先で分かること」を予告する（答えは最後）。
3. 本編は、問いに向かう3〜5つの場面。場面と場面は「ところが」「だから」「そこで」でつなぐ。
4. 疑似体験は「あなた」。本物の絵に戻る瞬間に「画家」に戻す。
5. 最後は本物の絵で終わり、冒頭と同じコマへつなぐ（画のループ）。最後の一文は冒頭の問いの答え。
6. 字幕は全文。ナレーションは読み辞書を通す（`knowledge/yomi.tsv`、`scripts/yomi.py`）。
7. 公開後は「視聴された割合」「平均視聴率」「ループ」「コメント」をエンゲージビューで見る。
