# サムネイルとタイトルの方針（2026-11-06 CEO決定）

**基本方針：最初は伸びている競合の型に寄せて再生回数を取りにいく。投稿を重ねてデータで学び、少しずつ自分たちのチャンネルに最適な形にしていく。**

## 守ること
- **型は借りるが、中身はオリジナル。** 構図・文字の置き方・色づかいなどの「型」は参考にしてよい。競合の絵・キャラ・ロゴ・言い回しをそのまま使うのは禁止。
- **中身と一致させる。** サムネとタイトルに書いたこと（問題数・難易度・テーマ）は動画の中身と同じにする。誇大・誤解を招く表現は使わない。
- 「認知症予防」など医学的な効果はうたわない（社則）。
- サムネは1280×720、2MB未満。スマホの小さな表示でも読めること。大きな文字は10字以内。
- **実際の問題の絵を使う。** 絵がこのチャンネルの売りなので、サムネでも見せる。

## 3つの段階
### 段階1：まねる（第1回〜第10回ごろ）
- 調査部が、競合（シニア向け間違い探し・脳トレ）でよく伸びている動画のサムネとタイトルを20本以上集める。vidIQ の伸びている動画の調査と、YouTube上の検索を使う。
- 共通する型を書き出し、下の「勝ちパターン」に記録する。例：絵の並べ方、文字の色と縁取り、難易度の見せ方、問題数・秒数の見せ方。
- 制作部はその型に沿ってサムネを作る。企画部はその型に沿ってタイトルを作る。

### 段階2：比べる（データがたまってから）
- **1回に変えるのは1か所だけ**（例：文字の色だけ、難易度の言い方だけ）。どこを変えたかを `outputs/<回>/thumbnail.md` に記録する。
- YouTube Studio の「テストと比較」（サムネの比較テスト）が使える場合は使う。設定はCEOの画面操作が必要なので、使うときは事業部長が会議でお願いする。
- 判定にはクリック率と平均視聴時間の両方を見る。クリック率だけ高くても、すぐ離脱されるサムネは失敗とする。
- 表示回数が少ないうちは判断しない。目安として、表示回数が1,000回を超えた回どうしで比べる。

### 段階3：自分の形にする
- 段階2で勝った要素を「勝ちパターン」に反映し、次の回から標準にする。
- 分析部は週次レポートで、サムネとタイトルの成績を必ず報告する。

## 担当
| 担当 | 仕事 |
|---|---|
| 調査部 | 競合サムネとタイトルの収集と型の抽出（段階1）。月1回、競合の新しい傾向を確認する |
| 企画部 | タイトル案を3つ出し、推奨を1つ選ぶ |
| 制作部 | サムネを作り、APIで動画に設定する（非公開アップロード時に同時に行う） |
| 監査 | サムネが中身と一致しているか、小さな表示で読めるか、競合のコピーになっていないかを確認する |
| 分析部 | クリック率・平均視聴時間を測り、勝ち負けを判定する |
